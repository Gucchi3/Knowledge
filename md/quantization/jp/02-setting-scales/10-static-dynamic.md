# 静的スケールと動的スケール

> スケールを推論前に固定するか、入力ごとに測るか。

重みのスケールは、モデルを学習すれば固定される。活性化のスケールは入力ごとに活性化が変わるので扱いが難しく、方法は2通りある。

| | 静的 | 動的 |
|---|---|---|
| 活性化のスケールを決める時期 | 推論前に1回 | 推論中に入力ごと |
| 実行時の処理 | なし | 範囲を測り、スケールを計算する |
| 入力が大きく変わる場合への適応 | 弱い | 強い |
| よく使われる場所 | 組み込み機器 | サーバ、大規模言語モデル |

## 静的スケール

スケールはサンプルデータ（[キャリブレーション](11-ptq.md)）か[QAT](12-qat.md)の中で測り、その後固定する。推論時、各層は固定したスケールを使う。デバイス上では、スケールは固定の乗数とシフト量になるので、実行時の演算は整数の乗算、加算、シフトだけで済む。

> [!WARNING]
> スケールを決めたデータと大きく異なる入力が来ると、値がクリップされたり、粗く丸められたりすることがある。

## 動的スケール

デバイスは実行中に各活性化テンソルの範囲を測り、そこからスケールを計算する。スケールは常にその時の入力に合う。

代償として、デバイスは量子化の前にテンソルの最大値を求める必要があり、データをもう1回なめることになる。さらに、新しいスケールを乗数とシフト量に変換するために除算が要る。これには時間と電力がかかるので、組み込み機器では通常、静的スケールを使う。

## 動的スケールが必要な層

attentionのスコアのように、入力ごとに大きく変わる値もある。こうした値には、入力ごとに測ったスケールを使うと精度をずっと保ちやすい。NEQを使った[SimA attention](../04-quantized-layers/21-sima-attention.md)は、これを整数演算だけで行い、デバイスは各テンソルのスケールを整数の除算で求める。
