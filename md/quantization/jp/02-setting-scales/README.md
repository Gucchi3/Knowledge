# スケールの決め方

スケールをいつ、どうやって決めるかを扱う。推論の前に固定するか入力ごとに測るか、再学習なしで決めるか（PTQ）学習の中で決めるか（QAT）の2つである。

このセクションを読むと、学習済みモデルを量子化する手順と、低ビットでQATが必要になる理由が分かる。
