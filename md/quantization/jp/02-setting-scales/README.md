# スケールの決め方

スケールをいつ、どうやって決めるかを扱う。推論前に固定するか入力ごとに測るか、再学習せずに決めるか（PTQ）学習の中で決めるか（QAT）、複数のテンソルでスケールを共有するか。

読み終えると、学習済みモデルを量子化するときの手順と、低ビットでQATが要る理由が分かる。
