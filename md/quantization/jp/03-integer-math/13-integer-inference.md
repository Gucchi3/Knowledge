# 整数推論

> 量子化した層を、デバイスで整数だけを使って計算する。積、INT32の和、バイアス、再量子化。

整数の回路しか持たないデバイスでも、量子化したモデルなら、入力の画素から出力まで整数だけで動かせる。このページでは、1つの層の中で何が起きているかを順に追う。

## 考え方

実数値はどれも、コードとスケールを使って $`r = S\,(q - Z)`$ と表せる。これを線形層 $`y = \sum_i w_i\, x_i + b`$ に代入してみる（重みは対称とする）。

```math
y = \sum_i S_w q_{w,i} \cdot S_x (q_{x,i} - Z_x) + b = S_w S_x \Big( \underbrace{\sum_i q_{w,i}\,(q_{x,i} - Z_x)}_{\text{整数}} + \frac{b}{S_w S_x} \Big)
```

括弧の中の和は、整数だけの計算である。スケールは $`S_w S_x`$ という1つの係数にまとまって、外に出ている。つまりデバイスは、整数の積をひたすら足し合わせ、スケールのことは最後に一度だけ考えればよい。

## 1つの層の手順

1. **積和（MAC）。** 入力のコードと重みのコードを掛け、その積を**アキュムレータ**と呼ぶ幅の広いレジスタに足し込んでいく。
2. **バイアスを足す。** バイアスは、和と同じスケール $`S_w S_x`$ の整数 $`q_b = \mathrm{round}(b / (S_w S_x))`$ として前もって用意しておく。だからアキュムレータにそのまま足せる。
3. **活性化。** ReLUは和を0以上に切りそろえる。丸める前のアキュムレータに対して行う。
4. **再量子化。** 和のスケール $`S_w S_x`$ はとても小さい。一方、次の層が欲しいのは、自分のスケール $`S_y`$ を持つ8ビットのコードである。[再量子化](14-requantization.md)で、和を整数の乗数とシフトで変換し、出力の形式に丸める。

出力のコードは次の層の入力になり、同じ手順が繰り返される。

## アキュムレータを32ビットにする理由

8ビットのコード同士の積には、最大16ビットが要る。層ではこの積を大量に足し合わせる。たとえば入力64チャネルの3×3畳み込みなら、576個である。足す個数が2倍になるごとに、和にはおよそ1ビットずつ余分に要る。32ビットのアキュムレータなら、最大の大きさの積を10万個以上足しても溢れないので、ほとんどの層はこれで足りる。INT8の推論で和とバイアスにINT32を使うのは、このためである。

## 最後の層

最後の層では再量子化を省き、INT32の和をそのままロジットとして使うことが多い。和は正確なので、いちばん大きいロジットを探すのにスケールは要らない。
