# BatchNormの畳み込み

> 直前の畳み込み層にBatchNormを取り込み、デバイスで動かす層を2つから1つに減らす。

学習が終わると、BatchNorm（BN）のパラメータはただの定数になる。そのため、畳み込み層や線形層の直後にあるBNは、その層の重みとバイアスに取り込める。これをBNの畳み込み（folding）と呼ぶ。

## 式で見る

線形層と、その後ろのBNは、次の計算をしている。

```math
y = W x + b, \qquad z = \frac{\gamma}{\sigma}\,(y - \mu) + \beta, \qquad \sigma = \sqrt{v + \epsilon}
```

$`\mu`$ と $`v`$ はBNが学習中に記録した平均と分散、$`\gamma`$ と $`\beta`$ は学習したスケールとシフトである。$`y`$ を $`z`$ の式に代入すると、次のようになる。

```math
z = \underbrace{\frac{\gamma}{\sigma}\,W}_{W_{fold}}\, x \;+\; \underbrace{\frac{\gamma}{\sigma}\,(b - \mu) + \beta}_{b_{fold}}
```

つまり $`z = W_{fold}\,x + b_{fold}`$ で、重みとバイアスを取り替えた1つの層と同じ計算になる。畳み込み層なら、$`\gamma / \sigma`$ を重みの出力チャネルごとに掛ければよい。

## 量子化の前に畳み込む理由

- デバイスで動かす層が1つで済み、BNの計算はまったく要らなくなる。
- デバイスが実際に使うのは、畳み込んだ後の重みである。先に重みを量子化してから畳み込むと、量子化した後で重みがまた変わってしまい、コードが形式の値からずれる。

> [!TIP]
> よく使われる順番は、浮動小数点で学習し、すべてのBNを畳み込み、畳み込んだ重みを量子化したモデルに読み込んでから、QATを回すというものである。LayerNormの代わりにBNを使い、すべての正規化を畳み込みで消してしまうモデルもある。
