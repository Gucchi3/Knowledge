# ReLUとReLU6

> 整数のコードに対するReLUとReLU6は、ただのクランプになる。再量子化の前の和に対して計算してよい。

ReLUとReLU6は、デバイス向けの小さなモデルで最もよく使われる活性化である。整数のコードの上では、どちらも上下に値を切りそろえる操作（クランプ）になる。

## ReLU

ReLUは正の値をそのまま残し、負の値を0にする：$`\mathrm{ReLU}(r) = \max(r, 0)`$。ゼロ点 $`Z`$ のコード $`q`$ は実数 $`S\,(q - Z)`$ を表すので、$`q < Z`$ のときに負になる。したがってコードの上では、次のようになる。

```math
\mathrm{ReLU}(q) = \max(q, Z)
```

スケールが対称（$`Z = 0`$）なら、これは $`\max(q, 0)`$ である。

## ReLU6

ReLU6は、6より大きい値も6で止める：$`\min(\max(r, 0), 6)`$。実数の6はコードでは $`\mathrm{round}(6 / S) + Z`$ なので、次のようになる。

```math
\mathrm{ReLU6}(q) = \min\big(\max(q, Z),\ \mathrm{round}(6 / S) + Z\big)
```

上限のコードは定数で、固定されたスケールから一度だけ計算しておけばよい。6がちょうど目盛りに乗らない場合は、丸めのせいで実数での上限が6から少しずれる。それでも学習時とデバイスで同じコードを使うので、両者の結果は一致する。

## 和に対して計算する

畳み込み層や線形層では、活性化を[再量子化](../03-integer-math/14-requantization.md)の前、INT32の和に対して計算できる。

- 和は正確な値なので、$`\max(acc, 0)`$ も正確に求まる。
- 再量子化はどのみち最後に範囲へ収める。だからReLUは再量子化に組み込める。下限を形式の最小値ではなく、出力のゼロ点にすればよい。

デバイスでReLUの計算がほとんどただで済むのは、このためである。

## 符号なしの出力

ReLUの後には負の値がない。そのため出力にはUINT8やUINT4のような $`Z = 0`$ の符号なし形式を使い、すべてのコードを実際の値に回せる（[対称量子化](../01-basics/03-symmetric.md#負にならないデータ)）。
