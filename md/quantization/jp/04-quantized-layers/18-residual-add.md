# 残差加算

> スケールの違う2つのテンソルを、整数演算のまま、丸め1回で足す。

残差接続は、ブロックの入力をそのまま出力に足す。式で書けば $`y = a + b`$ である。$`a`$ と $`b`$ は別々の層から来るので、スケールはたいてい違う。スケールが違うとコードをそのまま足しても意味がないので、まず両方を同じスケールに揃える必要がある。

## 出力のスケールに揃える

足し算の結果 $`y`$ にも、それ自身のスケール $`S_y`$ とゼロ点 $`Z_y`$ がある。実数で計算した和を $`y`$ のコードに直すと、次のようになる。

```math
q_y = \frac{S_a (q_a - Z_a) + S_b (q_b - Z_b)}{S_y} + Z_y
```

$`a`$ の側には $`S_a / S_y`$、$`b`$ の側には $`S_b / S_y`$ という比が掛かる。デバイスでは、[再量子化](../03-integer-math/14-requantization.md)と同じように、それぞれの比を整数の乗数とシフトで表す。

```math
\frac{S_a}{S_y} \approx \frac{M_a}{2^{n_a}}, \qquad \frac{S_b}{S_y} \approx \frac{M_b}{2^{n_b}}
```

## 丸めを1回で済ませる

すぐに思いつくのは、$`a`$ と $`b`$ をそれぞれ $`y`$ のスケールに再量子化し、丸めてから足すやり方である。これだと丸めが2回入り、誤差も2回分たまる。

丸めは次の手順で1回にできる。

1. それぞれに乗数を掛け、$`(q_a - Z_a)\,M_a`$ と $`(q_b - Z_b)\,M_b`$ を求める。
2. シフト量の小さい方を左シフトして、シフト量を大きい方に揃える。左シフトなので値は変わらない。
3. 2つを足す。
4. 丸めつきで1回だけ右シフトし、$`Z_y`$ を足して範囲に収める。

3まではどこにも丸めがないので、誤差は4の丸めで生じる半目盛り以内に収まる。

## スケールを揃えておけば乗算も要らない

$`a`$、$`b`$、$`y`$ が初めから同じスケールを持っていれば、比はどれも1になる。足し算は $`q_a + q_b`$ を範囲に収めるだけで済む。この考え方を残差ストリーム全体に広げたのが、次のページの[共有スケール](19-shared-scales.md)である。
