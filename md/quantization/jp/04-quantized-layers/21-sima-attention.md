# SimA attention

> softmaxの代わりにL1正規化を使うattention。指数関数が要らないので、整数演算だけで計算できる。

Transformerのattentionはsoftmaxを使う。softmaxは、スコアの1つずつに指数関数を計算し、その和で割る。指数関数も浮動小数点の割り算も、整数で計算するのは難しい。SimA（Simple Softmax-free Attention）は、softmaxをもっと単純な正規化に置き換えて、この問題を避ける。

## 考え方

通常のattentionは次の式で計算する。

```math
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{Q K^\top}{\sqrt{d}}\right) V
```

SimAはsoftmaxを使わず、その代わりに $`Q`$ と $`K`$ をL1ノルム（絶対値の和）で割っておく。ここでは、$`Q`$ と $`K`$ の各行（トークン1つ分）を、その行のL1ノルムで割るものとする。

```math
\hat{Q} = \frac{Q}{\lVert Q \rVert_1}, \qquad \hat{K} = \frac{K}{\lVert K \rVert_1}, \qquad \mathrm{SimA}(Q, K, V) = \hat{Q}\, \hat{K}^\top V
```

L1ノルムで割っておけば、$`\hat{Q}\hat{K}^\top`$ のスコアは一定の範囲を超えない。スコアが大きくなりすぎるのを防ぐのはsoftmaxの役目の1つだったので、softmaxをなくしても学習は不安定にならない。計算には指数関数がなく、割り算もトークンごとに1回で済む。

## 正規化を量子化に組み込む

L1ノルムは入力によって変わるので、デバイスは推論のたびにこれを計算する。NEQ（normalization-equivalent quantization）は、この正規化を量子化の中に組み込む。トークンをL1ノルムで割ることは、そのトークンのスケールをL1ノルムで割ることと同じだからである。デバイスは次の手順で計算する。

1. トークンのコードの絶対値を足し合わせ、L1ノルムを整数で求める。
2. 「スケール÷L1ノルム」という比を表す乗数とシフト量を、整数の除算で求める。
3. その乗数とシフト量で、トークンを再量子化する。

どの手順も整数演算である。スケールはトークンごとに求めてもよいし、ヘッドのテンソル全体で1つにまとめてもよい。まとめた方がデバイスでの計算は少ない。

## attentionの残りの計算

- $`\hat{Q} \hat{K}^\top`$ は、コードどうしの整数の行列積である。結果はattentionマップのスケールに再量子化する。$`1/\sqrt{d}`$ を掛けるなら、その分は再量子化の乗数に含めておけばよい。
- attentionマップと $`V`$ の積も整数の行列積で、そのあと再量子化する。
- 最後に、通常のattentionと同じく1×1畳み込み（線形層）で出力を射影する。

## デバイスに向いている点

- 指数関数も、その代わりの参照表も、浮動小数点の割り算も要らない。
- ブロック全体を、畳み込みと同じ整数の積和回路で計算できる。
- softmaxがないので、$`\hat{Q}(\hat{K}^\top V)`$ の順に掛けることもできる。$`\hat{K}^\top V`$ は $`d \times d`$ の小さな行列なので、トークン数が多いときはこの順の方が計算が少ない。
