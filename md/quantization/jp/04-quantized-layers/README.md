# 量子化した層

畳み込みと線形層以外の層を、整数演算で計算する方法を扱う。ReLU、残差加算、平均プーリング、softmaxを使わないattention（SimA）。

読み終えると、CNNや小さなTransformerを最初から最後まで整数で動かすのに必要な部品がそろう。
