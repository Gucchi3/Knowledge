# 量子化した層

畳み込みと線形層以外の層を整数で計算する方法を扱う。ReLU、残差加算と共有スケール、平均プーリング、softmaxを使わないattention（SimA）である。

このセクションまで読むと、CNNや小さなTransformerを入力から出力まで整数で動かすための部品がそろう。
