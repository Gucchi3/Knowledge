# BatchNormの畳み込み

> BatchNormを直前の畳み込み層に統合し、デバイスが2層ではなく1層を動かすようにする。

学習後、BatchNorm（BN）のパラメータは固定の数になる。そのため、畳み込み層や線形層の直後にあるBNは、その層の重みとバイアスに統合できる。これをBNの畳み込み（folding）と呼ぶ。

## 数式

線形層とその後のBNは次を計算する。

```math
y = W x + b, \qquad z = \frac{\gamma}{\sigma}\,(y - \mu) + \beta, \qquad \sigma = \sqrt{v + \epsilon}
```

$`\mu`$ と $`v`$ はBNの移動平均と移動分散、$`\gamma`$ と $`\beta`$ は学習したスケールとシフトである。$`y`$ を $`z`$ に代入すると次のようになる。

```math
z = \underbrace{\frac{\gamma}{\sigma}\,W}_{W_{fold}}\, x \;+\; \underbrace{\frac{\gamma}{\sigma}\,(b - \mu) + \beta}_{b_{fold}}
```

つまり $`z = W_{fold}\,x + b_{fold}`$ で、新しい重みと新しいバイアスを持つ1つの層になる。畳み込みなら、$`\gamma / \sigma`$ が重みの出力チャネルごとに掛かる。

## 量子化の前に畳み込む理由

- デバイスは2層ではなく1層を動かせばよく、BNはまったく要らない。
- デバイスが使う重みは、畳み込んだ後のものである。畳み込む前に重みを量子化すると、量子化の後で畳み込みが重みを再び変えてしまい、コードが形式に合わなくなる。

> [!TIP]
> 普通の順序は、浮動小数点で学習し、すべてのBNを畳み込み、畳み込んだ重みを量子化モデルに読み込み、それからQATを回す、である。LayerNormの代わりにBNを使い、すべての正規化を畳み込みで消すモデルもある。
