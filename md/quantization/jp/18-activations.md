# ReLUとReLU6

> 整数のコードに対するReLUとReLU6は単なるクランプであり、再量子化の前の和に対して実行できる。

ReLUとReLU6は、デバイス向けの小さなモデルの多くで使われる活性化である。整数のコードに対しては、どちらも単なるクランプになる。

## ReLU

ReLUは正の値を残し、負の値を0にする：$`\mathrm{ReLU}(r) = \max(r, 0)`$。ゼロ点 $`Z`$ のコード $`q`$ は $`S\,(q - Z)`$ を表し、これは $`q < Z`$ のとき負になる。よってコードに対しては次のようになる。

```math
\mathrm{ReLU}(q) = \max(q, Z)
```

対称なスケール（$`Z = 0`$）なら、これは $`\max(q, 0)`$ である。

## ReLU6

ReLU6は6より大きい値も切る：$`\min(\max(r, 0), 6)`$。実数6はコード $`\mathrm{round}(6 / S) + Z`$ なので、次のようになる。

```math
\mathrm{ReLU6}(q) = \min\big(\max(q, Z),\ \mathrm{round}(6 / S) + Z\big)
```

上限のコードは定数で、固定のスケールから1回だけ計算する。6がちょうど目盛りに乗らない場合、丸めのせいで実数での切る位置が6から少しずれるが、学習時とデバイスで同じコードを使うので、両者は一致する。

## 和に対して実行する

畳み込み層や線形層では、活性化を[再量子化](15-requantization.md)の前のINT32の和に対して実行できる。

- 和は正確なので、$`\max(acc, 0)`$ も正確である。
- 再量子化はどのみち出力をクランプする。そのため、デバイスはReLUを再量子化に統合できる。下限を形式の最小値ではなく出力のゼロ点にしてクランプすればよい。

デバイス上でReLUの負担がほとんどないのはこのためである。

## 符号なしの出力

ReLUの後は負の値がない。そのため、出力はUINT8やUINT4のような $`Z = 0`$ の符号なし形式を使い、すべてのコードを実際の値に使える（[対称量子化](03-symmetric.md#負にならないデータ)）。
