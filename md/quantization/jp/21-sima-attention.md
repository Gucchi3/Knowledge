# SimA attention

> softmaxを使わないattention：L1正規化したクエリとキーで、デバイスが整数演算だけで計算できる。

Transformerのattentionはsoftmaxを使い、スコアごとに指数関数と浮動小数点の除算が要る。これらは整数で計算するのが難しい。SimA（Simple Softmax-free Attention）は、softmaxをはるかに単純な正規化で置き換える。

## 考え方

通常のattentionは次のとおりである。

```math
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{Q K^\top}{\sqrt{d}}\right) V
```

SimAはsoftmaxをやめ、代わりに $`Q`$ と $`K`$ をL1ノルム（絶対値の和）で正規化する。このページでは、$`Q`$ と $`K`$ の各トークン（行）をそれぞれのL1ノルムで正規化する。

```math
\hat{Q} = \frac{Q}{\lVert Q \rVert_1}, \qquad \hat{K} = \frac{K}{\lVert K \rVert_1}, \qquad \mathrm{SimA}(Q, K, V) = \hat{Q}\, \hat{K}^\top V
```

正規化によってスコアは一定の範囲に収まる。これはsoftmaxが果たしていた役割なので、学習は安定したまま保てる。指数関数はなく、除算はトークンごとに1回だけである。

## 整数演算：正規化と量子化を1段で行う

L1ノルムは入力に依存するので、デバイスは実行時にこれを計算しなければならない。NEQ（normalization-equivalent quantization）は、正規化を量子化に統合する。トークンをL1ノルムで割ることは、そのスケールをL1ノルムで割ることと同じである。そこでデバイスは次の手順を踏む。

1. トークンのコードの絶対値を足し合わせ、L1ノルム（整数）を得る。
2. 「スケール÷L1ノルム」という比の乗数とシフト量を、整数の除算で求める。
3. それを使ってトークンを再量子化する。

これはすべて整数演算である。スケールはトークンごとに1つ求めても、ヘッドのテンソル全体で1つ求めてもよく、後者の方がデバイス上では安い。

## attentionの残りの部分

- $`\hat{Q} \hat{K}^\top`$ はコードどうしの整数の行列積である。結果はattentionマップの形式に再量子化し、$`1/\sqrt{d}`$ は乗数の固定部分に組み込む。
- attentionマップと $`V`$ の積も整数の行列積で、その後に再量子化が続く。
- 通常のattentionと同じく、1×1畳み込みで結果を射影する。

## デバイスに向いている理由

- 指数関数も、そのための参照表も、浮動小数点の除算も要らない。
- ブロック全体が、畳み込みと同じ整数の積和ハードウェアで動く。
- softmaxがないので、積を $`\hat{Q} (\hat{K}^\top V)`$ の順に計算することもできる。$`\hat{K}^\top V`$ は $`d \times d`$ の小さな行列なので、トークンが多いときはこの順の方が安い。
